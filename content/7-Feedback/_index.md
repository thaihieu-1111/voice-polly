# Feedback on the First Cloud AI Journey Program

## Overall evaluation

First Cloud AI Journey gave me a structured AWS learning path connected to a practical product. Instead of studying each service only in theory, I had to select, integrate, deploy, and troubleshoot multiple components in Polly Voice. This was the program's greatest value because it showed me the difference between an architecture diagram and an operational system.

## What I valued most

### Practice-oriented content

Cloud fundamentals, serverless computing, storage, databases, authentication, and deployment could all be applied directly to my project. Preparing a workshop required me not only to complete each task but also to explain the process clearly enough for another learner to reproduce it.

### Mentor and community support

The mentors and community created opportunities to ask questions, research independently, and receive feedback. Guidance was usually provided through direction and suggestions, encouraging me to investigate root causes instead of copying a ready-made answer.

### Exposure to real-world perspectives

Sessions on Cloud Practitioner, SLA and monitoring, AWS Security Agent, and Agentic AI Build Week showed applications of AWS beyond my personal project. I particularly valued monitoring from the customer-journey perspective, tool- and data-grounded agent design, and the importance of limiting MVP scope during a hackathon.

### Broad skill development

In addition to technical skills, the program helped me practice progress management, English technical reading, blog writing, bilingual reporting, architecture presentation, and reflection after each stage.

## Challenges

- AWS covers a large body of knowledge, while practice time for each service is limited.
- Integrating multiple services introduced IAM, CORS, authentication, data-format, and payload-limit issues.
- Some sample materials and the Hugo theme used older versions and required compatibility fixes.
- Developing the project while producing a workshop, blogs, and reports required stronger time management.
- Cloud cost and resource cleanup needed continuous attention.

## Suggestions for improvement

1. Provide a weekly checklist with minimum deliverables for the project, blogs, workshop, and report.
2. Add a focused session on IAM, Cognito, CORS, and serverless troubleshooting.
3. Provide starter templates for CloudWatch dashboards, alarms, AWS Budgets, and resource-cleanup checklists.
4. Schedule short architecture or code reviews at project milestones so learners receive feedback earlier.
5. Update the Hugo template and deployment documentation for current tool versions, including common troubleshooting guidance.
6. Add more peer-review sessions where learners test one another's workshops for clarity and reproducibility.
7. Include guidance on presenting projects in English and preparing a concise technical demo.

## Future expectations

I hope the program continues combining independent study, project practice, documentation, and community activities. I would like to join more advanced workshops on serverless, observability, security, and generative AI, and share my Polly Voice experience with future learners.

## Conclusion

First Cloud AI Journey helped me establish practical AWS foundations, become more confident when learning new services, and clarify my interest in cloud-related roles. I would recommend the program to learners who are willing to study independently and turn AWS knowledge into a demonstrable product, while recognizing that consistent time management and persistence are essential.
