# First Cloud AI Journey Self-Assessment

During the **Workforce Bootcamp – First Cloud AI Journey** at **Amazon Web Services Vietnam Company Limited**, from **June 1, 2026 to August 15, 2026**, I strengthened my cloud fundamentals, practiced deploying AWS services, and developed a more systematic approach to independent learning.

My main project was **Polly Voice**, a serverless web application that provides Text-to-Speech through **Amazon Polly** and Speech-to-Text through **Amazon Transcribe**. I worked with a React frontend, a Node.js backend, Amazon Cognito authentication, API Gateway and Lambda, private media storage in Amazon S3, conversion history in DynamoDB, and frontend deployment through AWS Amplify.

I also maintained a worklog, prepared a bilingual proposal and workshop, wrote technical blogs, and attended events about AWS Cloud, monitoring, security, and agentic AI. These activities improved my technical, documentation, presentation, and knowledge-synthesis skills.

## Achievements

- Developed an end-to-end understanding of an **AWS Serverless** application.
- Integrated Amazon Polly and Amazon Transcribe into a practical project.
- Used presigned URLs for direct S3 upload and download, reducing API and Lambda payload processing.
- Applied Cognito JWT authentication, private S3 storage, CORS controls, and least-privilege access.
- Practiced Infrastructure as Code and repeatable build and deployment workflows.
- Improved technical research, troubleshooting, worklog writing, and bilingual documentation.
- Expanded my knowledge through sessions on Cloud Practitioner, SLA and monitoring, AWS Security Agent, and Agentic AI Build Week projects.
